# Dự án Quản lý Trung tâm Tiếng Anh (TTA)

## Giới thiệu
Đây là dự án **website quản lý học phí** dành cho Trung tâm Tiếng Anh (TTA), giúp tối ưu hóa quy trình lưu trữ và *tra cứu thông tin đăng ký* của học viên.

## Cấu trúc thư mục
| Thư mục/File | Nội dung |
| --- | --- |
| `data/` | Chứa các file dữ liệu Excel, bao gồm bảng học phí |
| `bai_lam_ngay3.md` | File bài tập thực hành Markdown và Excel |
| `README.md` | Tài liệu giới thiệu và hướng dẫn tổng quan về dự án |

## Quy trình đăng ký học tại TTA
1. Tư vấn viên tiếp nhận thông tin và định hướng khóa học phù hợp cho học viên.
2. Học viên điền form ghi danh và hoàn thành đóng học phí.
3. Trung tâm tiến hành xếp lớp và gửi thông báo lịch học chi tiết qua email.
